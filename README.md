## dwm keybinds
- Super + {1,2,3...0} - Select tag
- Super + Shift + {1,2,3...0} - Move focused window to tag
- Super + c - close focused window
- Super + b - show/hide the status bar
- Super + d - decrease number of windows in master area
- Super + i - increase number of windows in master area
- Super + h - decrease master area size
- Super + l - increase master area size

- Super - j - move focus up the stack
- Super - k - move focus down the stack

- Super + Return - Zoom/Move window to master area
- Super + Shift + c - Kill (close) focused window
- Super + t - Set tiled layout
- Super + f - Set floating layout
- Super + m - Set monocle layout
- Super +  space - Toggle between layouts
- Super + Shift + space - Toggle floating for focused window
- Super + backtick - Quake Terminal Window
